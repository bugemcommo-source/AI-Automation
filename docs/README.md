# Published page

`index.html` is served by GitHub Pages at
<https://bugemcommo-source.github.io/AI-Automation/>

It is a standalone, self-contained page — no build step, no dependencies.
Edit it directly and push; Pages redeploys within a minute or so.

| File | Purpose |
|---|---|
| `index.html` | The page itself |
| `og-card.png` | Link-preview image used by the `og:image` tag |
| `.nojekyll` | Stops GitHub running Jekyll over the folder |

The same content is also published as a Claude artifact. The two are
separate copies — updating one does not update the other.
